# 修仙 H5

本仓库对应 `mobile-port/app/`，包含手机竖版游戏代码和运行所需的界面、场景、角色、装备、动画、音频等资源。

## 本地运行

安装 Python 3，在仓库根目录执行：

```sh
python -m http.server 4173 --bind 127.0.0.1
```

打开 <http://127.0.0.1:4173/>。请通过 HTTP 服务访问，不要直接双击 HTML 文件。

原完整工程的专用服务提供额外诊断接口；上述静态服务不收集该诊断日志。

## 目录

- `index.html`：手机游戏入口。
- `engine.html`、`scripts/`、根目录 JSON：原游戏运行时和数据。
- `mobile/`：手机功能、运行时连接层、战斗逻辑与素材。
- `ui/`：界面、装备、洞府和相关素材。
- `images/`、`media/`、`fonts/`、`icons/`：纹理、音频、字体和图标。
- `hero-frame-view/`：主角待机、攻击、受击和技能序列帧展示。
- `hero-lab/`：动作与轴心对齐候选展示。

当前 `package.json` 是原游戏的运行配置，不是 npm 构建配置；无需执行 `npm install` 或构建步骤。

## 发布与存档

将仓库内的运行文件放在静态站点根目录，通过 HTTP/HTTPS 访问；不要发布 `.git/`。资源有动态引用，部署时应保持原目录结构和文件名。

游戏存档在浏览器本地存储中，不会随 Git 提交上传。根目录 `save.json` 是游戏自带的数据文件，应保留。

本仓库不包含完整工程的高清源稿、制作记录、Android 工具链、安装包和模拟器数据。美术制作源文件仍保存在本地完整工程的 `design/` 目录中。
