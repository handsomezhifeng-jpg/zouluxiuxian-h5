# 洞府弟子序列帧

内置 image_gen 生成的浅灰青玉汉服修士，6列×4行透明图集，固定256×256画布、统一缩放。24张独立PNG与 atlas.png 内容对应。行分别为斜前行走、斜后行走、行礼、俯身劳作；左右围绕显式轴心镜像。frames.json逐帧保存语义轴心，未按包围盒重新居中或归一化。

固定动作采用同一支撑鞋底位置，行走采用双腿中点的水平位置；世界位移完全由庭院路径计算。人工轴心标记与四行对照见 qa/cave-c-approved/disciples-contact.png；108px和216px动作预览为本目录 preview-*.gif。切帧脚本及标记坐标见 qa/cave-c-approved/prepare-disciples.py。

提示词：同一成年修士，灰绿汉服、米白内衫、黑布鞋、发髻，细腻水墨矿物色，俯视35度；6×4固定网格；前后两个方向各6帧行走、6帧行礼、6帧劳作。保持服装、比例、躯干高度，透明背景，不含文字、阴影或武器。静止动作固定支撑鞋底，行走固定双腿中点；单次行礼从站立到俯身再回到站立。

运行时最多显示6名弟子，人数不超过真实宗门人数，任务目的地跟随当前有派驻的建筑。途经庭院道路，到达后行礼并劳作。视觉动作不另行发放资源，产出沿用原经营结算。场景退出取消动画，缩放拖动与建筑命中保持原逻辑。
