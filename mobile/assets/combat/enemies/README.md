# 前十种妖兽入版

按游戏物种 ID 1–10 接入：乌鬃野猪、白马、沙漠土狼、利齿虎、旋龟、灵兔、雪貂、沙蝎、蝎尾狮、白象。注意蝎尾狮、白象的原图 artId 为13、16，运行映射使用物种ID，避免串图。首领沿用相同物种资源。

野猪复用原8帧图集并从首帧提取同尺寸待机。其余9种由内置 imagegen 各生成一个透明底2×2图集：待机、蓄势、命中、收势。完整原图为 `{id}-source.png`，切分帧 `{id}-{0..3}.webp`，运行图 `{id}-idle.webp`、`{id}-attack.webp`。`manifest.json` 记录源图切分坐标、原画图ID、帧数、攻击类别与命中点。

`tools/pack-enemy-roster.py` 使用透明轮廓连通区域切分，避免按格硬裁断越格尾巴；同物种四帧使用同一缩放比例、统一脚底基线。`enemy-art.js` 由清单生成，作为运行静态映射。运行只按需加载当前物种图集；加载失败仍显示对应待机图。低动态偏好时保留待机并减弱反馈。

`combat-sprites.js` 播放430ms攻击，四帧命中点在46%；原修士与野猪时点保持不变。`adventure-combat.js` 依真实回合事件驱动位移、受击、伤害数字及特效，命中时间与姿态同步；换怪、结算、掉落和关卡均由原系统处理，不改变存档或解锁。

验收：`analysis/enemy-roster-check.cjs` 在隔离页面逐一检查10种加载、攻击姿态变化、回待机、事件反馈清理、物种映射、低动态与375/390/750宽布局。结果和逐种待机/攻击截图位于 `qa/enemy-roster`。可交互预览：`mobile/previews/enemy-roster.html`。
